# L05 · Multi-turn Test Plan — PayPilot

ДЗ_4 курсу AI Quality Engineering. Документ — [`multi-turn-test-plan.md`](multi-turn-test-plan.md), діалогові кейси — [`l05_dialogs.jsonl`](l05_dialogs.jsonl), сирі звіти — `reports/`.

## Запуск
Покладіть `l05_dialogs.jsonl` у `sets/` кіту `paypilot-l05-eval` (стенд PayPilot піднятий на `localhost:8000`) і виконайте в корені кіту:

    docker compose run --rm eval --set l05_dialogs --dry-run
    docker compose run --rm eval --set l05_dialogs --profile clean
    docker compose run --rm eval --set l05_dialogs --profile lesson-05

Поріг згортки задають самі кейси (`summarize_after: 2`), кожен кейс проганяється 5 разів (`runs: 5`).

`set_hash`: `4665fe851efa`

Інваріант-перевірки основного сценарію з лабораторної (розділ 4.1 документа): `invariants.py`, запуск з кореня кіту — `docker compose run --rm --entrypoint python eval invariants.py --profile lesson-05 --runs 5`.
